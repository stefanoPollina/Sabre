Current-build sample library and live sample hot-swap updater

This updater starts with your latest published main/index.html, not an older saved SABRE. It applies only the two requested features and produces a replacement index.html for GitHub.

Select “Fetch current published source” to build the new index.html. If GitHub blocks the request, choose a downloaded copy of your latest index.html instead.
  • Sample bank: every audio file below SABRE BREAKS/, including renamed and nested folders.
  • Hot-swap: keep old sample playing while replacement decodes; commit at the next master bar, with a short crossfade.
  • Preserved: other tracks, shared clock, track settings, sequences, mixer and newer UI code.

No repository files are changed by this updater. After downloading, replace index.html in the SABRE GitHub repository. Keep a copy of the original first. The updater refuses to produce an output if the source has changed enough that the patch cannot be applied safely.
